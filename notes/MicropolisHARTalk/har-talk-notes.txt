I started working on SimCity about 1992.

I saw SimCity in college, fell in love with it, wanted to figure out
how it worked, do stuff with the user interface.

So I jumped at the change to port it to the Sun workstation.

First I made a version of it with the NeWS window system, James
Gosling's PostScript based window system.

Then I developed an X11 version that was multi player.

DUX Software sold both of those as commercial products for Unix.

But the contract with Maxis expired after ten years.

In the mean time on I went on to Maxis to work on The Sims with Will
Wright.

Later I dredged up the SimCity code, and we talked EA into making it
open source under GPLv3.

The thing that convinced them it was a good idea was the OLPC project.

It's focused on constructionist education: learning by building
things.

SimCity is pretty much the quintessential constructionist educational
game.

But it needs to be opened up to be even better.

The OLPC project is based on Seymour Papert's ideas about teaching
children to program when they're very young.

It's inspired by Alan Kay's ideas about the DynaBook and object
oriented programming, and learning how do kids learn?

One of the important things about constructionism is kids helping each
other, communicating, and teaching each other.

I took the X11 version of SimCity. I had made multi player for
X-Windows. But I simplified that and took the multi player features
out for the OLPC, since they were rough, complex and didn't scale.

Now that's on the OLPC.

But what we really needed to do was make a new version that had a much
better user interface designed to take advantage of the things the
OLPC can do.

So they used Python as the scripting langauge for OLPC.

The architecture of the web server is:

There's a C++ game.

I'm using SWIG, which is a tool for making wrappers for libraries, and
plugging them into extenstion languages.

And it lets you get your library to a whole bunch of different
extension languages.

Right now it's Python, but it could be Lua or Java or whatever.

So then there's another layer which is gluing the game into Python.

The nice thing about SWIG is that you can subclass your C++ classes in
Python, and then just script in a nice language.

It's all open source stuff, and the web server does http, and it does
Adobe AMF, which is kind of like binary JSON.

I'm doing the client in another open source scripting language called
OpenLaszlo.

OpenLaszlo is like JavaScript and XML that compiled into Flash.

The Sims has something called "The Sims Exchange", where when you save
your game file, it also writes out a bunch of web files that describe
your house, you family, the story you've told about them with
pictures, and then it uploads that to the web.

So really playing the game is a web publishing tools.

I want to apply those ideas to SimCity, and that would manifest in the
form of a newspaper.

So you could act as a journalist, and when something happened, these
events in the game are generating opportunities for you to click on it
and open it up and write about what your interpretation of it is, and
automatically push it into a wiki page or a blog.

So basically the result of playing a game will be this rich save file
which has rich points of interest with stories attached to them.

You could look at it geographically as a map, to see all the points of
interest.

You could look at it as a calandar, like a blog, and then things that
happen with the story can link to a save file, so you can then jump
back into the game at that point.

Basically I want to make like TiVo for SimCity, is the eventual goal.

You have all these save file snapshots, and you can fast forward and
reverse by re-playing the edits that you did.

You can imagine that when you play a game, at any point if you decide
"let's raise taxes", you make a checkpoint there, and then you can
revisit that decision, and then branch reality out to another thing if
you didn't raise taxes, and then see what happens.

I want players to be able to make a tree of possibilities, and then
share all these save files, and then comment on them, and write about
them.
